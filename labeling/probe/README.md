# labeling/probe

One-off feasibility probes. `laya_probe.py` measures Laya load time, peak
memory and per-sample latency on CPU, and compares its predictions against a
labelled sample file supplied **by path** — sample files are read from the
planning directory and are never copied into this repository (NR-0000 §2.7.3).
